# NOVA HELPER

Оверлей-справочник правил и законов NOVA RP (GTA 5). Готово:

| Часть | Папка | Статус |
|---|---|---|
| Сбор базы правил и законов с форума | `parser/` | готово, 30 тестов |
| Дизайн-токены (цвета и шрифт форума) | `design/tokens.css` | готово |
| Программа для Windows (Tauri 2) | `app/` | следующий этап |
| ИИ-помощник (прокси + RAG) | — | следующий этап |

## Как работает сбор базы

1. Каждые 3 часа GitHub Actions запускает `parser` (файл `.github/workflows/rules-db.yml`).
2. Парсер открывает форум в настоящем браузере Chromium и проходит проверку «Checking your browser». Это бесплатно. Если браузер не справился, страница берётся через Firecrawl.
3. Серверы находятся сами: все разделы «Сервер | …» в категории 21. Путь до законов ищется по названиям: «Государственные организации → Правительство → Законодательная база». Новый сервер появится в базе автоматически. Пропавший уходит в архив только после 3 прогонов подряд.
4. Каждая тема разбирается в дерево:
   - разделы, главы, статьи, пункты, части;
   - наказания (перманентные баны и ЧС помечаются отдельно);
   - звёзды розыска и юрисдикция;
   - примечания, исключения, пояснения, уточнения;
   - картинки.
5. Поправки «Было / Стало» из ответов в теме накладываются на основной текст. Если основной текст на форуме остался старым, игрок увидит обе редакции. Вы получите уведомление в задачах (Issues) репозитория.
6. База публикуется в ветку `data`: `manifest.json` (подписан), `docs/…json`, `changelog/…json` («было/стало» для экрана «Что изменилось»).

Защита от ошибок:
- Если форум отдал заглушку или документ «похудел» больше чем вдвое, публикуется прошлая версия.
- Если обход нашёл меньше 70% документов, публикация отменяется целиком.

## Запуск (один раз, ~10 минут)

1. Создайте репозиторий на GitHub (можно публичный — тогда Actions бесплатны без лимита) и загрузите туда эту папку.
2. Сгенерируйте ключ подписи базы:
   ```
   cd parser && npm install && npx tsx src/cli.ts keygen --out keys
   ```
   - Содержимое `keys/nova-signing.key.pem` положите в секрет `NOVA_SIGNING_KEY`: Settings → Secrets and variables → Actions → New repository secret.
   - `nova-signing.pub.pem` понадобится программе, его можно хранить открыто.
   - Сам `.pem` в репозиторий не загружайте.
3. Необязательно: ключ Firecrawl положите в секрет `FIRECRAWL_API_KEY`. Он нужен только как запасной вариант.
4. Вкладка Actions → «База правил NOVA RP» → Run workflow. После первого прогона появится ветка `data`.

Адреса базы для программы (основной и запасной):
- `https://raw.githubusercontent.com/<вы>/<репозиторий>/data/manifest.json`
- `https://cdn.jsdelivr.net/gh/<вы>/<репозиторий>@data/manifest.json`

## Для разработки

```
cd parser
npm install
npm test                                         # тесты на сохранённых страницах форума
npx tsx src/cli.ts offline --out out-offline     # сборка базы без сети
npx tsx src/cli.ts scrape --out out --via browser   # живой сбор (нужен Chromium: npx playwright-core install chromium)
```

Модули `parser/src`:

| Файл | Что делает |
|---|---|
| `forum.ts` | разбор страниц XenForo, распознавание заглушки антибота |
| `text.ts` | HTML сообщения → строки |
| `structure.ts` | строки → дерево пунктов |
| `punishments.ts` | наказания |
| `amendments.ts` | поправки «Было/Стало» |
| `discover.ts` | автопоиск серверов и законов |
| `fetcher.ts` | браузер + Firecrawl |
| `publish.ts` | валидация, diff, манифест, подпись |
